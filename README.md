# Sistema de Controle de Estoque

Projeto em **Java (Swing + MySQL)** usando arquitetura **MVC + DAO + Service**.

## 📂 Estrutura do projeto
- `model/` → classes de domínio (Produto, Categoria, Usuário)
- `dao/` → acesso ao banco de dados (MySQL)
- `service/` → regras de negócio
- `controller/` → controle de fluxo entre view e lógica
- `view/` → telas Swing
